# 営業AIプラットフォーム

「リサーチ → 大手開拓 → 商談分析 → CRM整備」の4つを、
1つの画面でぐるぐる回すための営業支援システムです。
AI部分には Claude API を使います。

| 機能 | できること |
| --- | --- |
| **リサーチ** | 会社名から、Web上の公開情報(公式サイト・ニュースなど)を検索し、<br>事業内容・最近の動き・想定課題・初回商談の質問案をまとめます。<br>出典URLも表示します。課題は「事実」と「推測」を分けて表示します。 |
| **大手開拓** | 企業規模・決裁者との接点・商談の有無から優先度を自動計算し、<br>攻める順に並べます。キーパーソンの仮説、アプローチ手順、<br>初回メール文面まで含む「開拓プラン」をAIが作ります。 |
| **CRM整備** | 重複・表記ゆれ・未入力・期限切れの案件を自動で検出し、<br>ボタン1つで統合・修正できます。名刺やメール署名を貼り付けると、<br>AIが項目を読み取って登録します。CSVの入出力にも対応しています。 |
| **商談分析** | 議事録や文字起こしから、要約・BANT・受注確度・次のアクション・<br>営業コーチング・お礼メールを作ります。<br>結果はワンクリックでCRMの商談情報に反映できます。 |

## 動かし方

必要なもの:Node.js 20.12 以上

```bash
npm install
npm start
```

ブラウザで http://localhost:3000 を開き、
ホーム画面の「サンプルデータを入れる」を押すと、すぐに試せます
(サンプルの会社・人物はすべて架空です)。

### AIを本番で使う(APIキーの設定)

APIキーがない状態では **デモモード** で動き、
AIの結果欄には「架空のサンプル文」が表示されます。
実際にAIを使うには、次の手順で設定してください。

1. `.env.example` をコピーして `.env` という名前にする
2. `ANTHROPIC_API_KEY=` の後ろに、Claude APIのキーを書く
3. サーバーを再起動する(`npm start`)

画面右上の表示が「AI接続中」になれば成功です。

### 精度を上げるコツ

「設定」タブで **自社の提供サービス** を具体的に書いてください。
AIはこの内容をもとに、提案の切り口や開拓プランを考えます。

## 構成

```
server.js        Webサーバー(APIの入口)
lib/ai.js        Claude APIを呼ぶ部分(リサーチ/開拓プラン/取り込み/商談分析)
lib/crm.js       ルールで行うCRMチェック(重複・未入力・優先度・CSV)
lib/db.js        データ保存(data/db.json に保存)
lib/seed.js      サンプルデータ
public/          画面(HTML/CSS/JavaScript)
test/            自動テスト(npm test)
```

## 注意点・今後の課題

- データは `data/db.json` という1つのファイルに保存しています。
  少人数での試験運用向けです。本格運用では、データベースへの移行と
  ログイン機能(誰が何を見られるかの管理)の追加が必要です。
- AIの出力は「下書き」です。特に、リサーチの「推測」や
  キーパーソンの仮説は、必ず人が確認してから使ってください。
- Web検索を使うリサーチは、1回あたり1〜3分ほどかかり、
  API利用料も他の機能より多めにかかります。
