# 営業AIプラットフォーム

「リサーチ → 大手開拓 → 商談分析 → CRM整備」の4つを、
1つの画面でぐるぐる回すための営業支援システムです。
AI部分には Claude API を使います。

**社内で使う** ことも、**他社に販売する(SaaS)** こともできる作りにしています。

## 機能

| 機能 | できること |
| --- | --- |
| **リサーチ** | 会社名からWebを検索し、事業内容・最近の動き・想定課題・初回商談の質問案をまとめます。<br>出典URLも付き、課題は「事実」と「推測」を分けて表示します。 |
| **大手開拓** | 優先度を自動で点数化して並べ、キーパーソンの仮説・アプローチ手順・初回メール文面まで作ります。 |
| **CRM整備** | 重複・表記ゆれ・未入力・期限切れを検出してワンクリックで修正します。<br>名刺やメール署名からのAI取り込み、CSVの入出力にも対応しています。 |
| **商談分析** | 議事録から、要約・BANT・受注確度・次のアクション・コーチング・お礼メールを作ります。<br>結果はワンクリックでCRMに反映できます。 |
| **外部CRM連携** | **Salesforce・HubSpot** から会社・担当者・商談を取り込みます。<br>商談分析の結果(ステージ・確度・次のアクション・金額)を、元のCRMへ自動で書き戻します。 |

## 販売(SaaS)に必要な仕組み

| 項目 | 内容 |
| --- | --- |
| 会社ごとのデータ分離 | 契約企業(テナント)ごとにデータを分けて保存し、他社のデータには一切アクセスできません。 |
| ログイン・権限 | オーナー/管理者/メンバーの3段階。メンバーは招待リンクで追加します。 |
| 料金プラン | 社内利用・無料トライアル(14日)・スタンダード・エンタープライズ。<br>AIの月間利用回数とユーザー数に上限をかけられます(`lib/plans.js`)。 |
| 利用量の記録 | 会社ごと・機能ごとに、AIの利用回数とトークン数(=原価)を記録します。 |
| 操作ログ | ログイン・削除・出力・連携などの操作を記録します(監査・情報漏えい調査用)。 |
| データの持ち出し・解約 | 全データのダウンロードと、全データの完全削除(解約)ができます。 |
| セキュリティ | パスワードのハッシュ化(scrypt)、ログイン試行回数の制限、CSRF対策、<br>セキュリティ用HTTPヘッダー、外部CRMの認証情報の暗号化(AES-256-GCM)、CSV数式インジェクション対策。 |
| 規約 | 利用規約・プライバシーポリシーの **ひな形**(`public/terms.html`、`public/privacy.html`)。 |

## 動かし方

必要なもの:Node.js 22.13 以上

```bash
npm install
cp .env.example .env   # 必要に応じて中身を編集
npm start
```

ブラウザで http://localhost:3000 を開きます。

1. 最初の画面で「会社名・お名前・メール・パスワード」を登録すると、
   その人が **オーナー** になります(プランは「社内利用」=上限なし)。
2. ホームの「サンプルデータを入れる」で、すぐに動きを試せます(内容はすべて架空です)。
3. 社員の追加は「管理 → メンバー」から招待リンクを発行して、本人に送ります。

### 社内利用モードと販売モード

| 設定(`.env`) | 動き |
| --- | --- |
| `ALLOW_SIGNUP=false`(初期値) | **社内利用モード。** 最初の1社だけ登録でき、以降は招待制です。 |
| `ALLOW_SIGNUP=true` | **販売モード。** ログイン画面から誰でも申し込めます(14日間の無料トライアルで開始)。 |

### AIを本番で使う

`.env` の `ANTHROPIC_API_KEY=` に Claude API のキーを書いて再起動します。
未設定の場合は **デモモード** で動き、AIの結果欄には架空のサンプル文が出ます。

### 外部CRM連携の設定

「管理 → 外部CRM連携」から設定します。

- **Salesforce:** 「接続アプリケーション」で
  *OAuth 2.0 クライアントログイン情報フロー* を有効にし、実行ユーザーを指定します。
  組織のURL・コンシューマー鍵・コンシューマーの秘密を入力してください。
  実行ユーザーには、取引先・取引先責任者・商談の参照権限と、商談の編集権限が必要です。
- **HubSpot:** 「非公開アプリ」を作成し、アクセストークンを入力します。
  必要なスコープ:`crm.objects.companies.read` / `crm.objects.contacts.read` /
  `crm.objects.deals.read` / `crm.objects.deals.write`

ステージは、Salesforce の標準フェーズ/HubSpot の標準パイプラインに合わせて自動変換します
(`lib/integrations/*.js` の `DEFAULT_STAGE_MAP`)。

### 運営者用コマンド

```bash
npm run admin -- tenants                         # 契約企業の一覧(利用回数・トークン数つき)
npm run admin -- set-plan <テナントID> standard  # プラン変更
npm run admin -- extend-trial <テナントID> 7     # トライアル延長
```

### 本番環境へのデプロイ

`Dockerfile` を同梱しています。Cloud Run・AWS App Runner・Render など、
**永続ディスク(ボリューム)を付けられる** サービスで動かしてください。

本番では、次の環境変数が必須です。

- `NODE_ENV=production`
- `APP_ENCRYPTION_KEY`(作り方は `.env.example` を参照)
- `ANTHROPIC_API_KEY`
- `DATA_DIR`(永続ディスクのパス)

## テスト

```bash
npm test
```

テナント間のデータ分離、ログイン・権限、CSRF対策、プラン上限、
Salesforce・HubSpot の取り込みと書き戻し(偽のサーバー応答を使用)などを確認します。

## 構成

```
server.js                   起動用
lib/app.js                  Webサーバーの処理(API・認証・権限)
lib/db.js                   データベース(SQLite。テナントごとに分離)
lib/auth.js                 パスワード・セッション・試行回数制限
lib/plans.js                料金プランと上限
lib/secrets.js              秘密情報の暗号化
lib/ai.js                   Claude API(リサーチ/開拓プラン/取り込み/商談分析)
lib/crm.js                  ルールで行うCRMチェック(重複・未入力・優先度・CSV)
lib/integrations/           Salesforce・HubSpot 連携
scripts/admin.js            運営者用コマンド
public/                     画面
test/                       自動テスト
```

## 販売開始までに残っていること

このコードだけでは足りず、事業として別途準備が必要なものです。

1. **課金(決済)の自動化:** 今はプラン変更を運営者がコマンドで行います。
   Stripe などの決済サービスとの連携が必要です。
2. **メール送信:** 招待やパスワード再設定はリンクを手動で渡す方式です。
   自動送信には、メール配信サービスとの連携が必要です。
3. **規約類の確定:** 利用規約・プライバシーポリシーはひな形です。弁護士の確認が必要です。
   特に、AI(米国の Anthropic 社)へのデータ送信は、個人情報の外国への提供にあたる可能性があります。
4. **大規模化への備え:** SQLite は1台のサーバー向けです。
   契約社数が増えたら、PostgreSQL などへの移行を検討してください。
5. **外部CRMの実機確認:** Salesforce・HubSpot 連携は、公開されているAPI仕様に沿って実装し、
   偽の応答で自動テストしています。実際のアカウントでの動作確認がまだ必要です。
6. **SSO(シングルサインオン)・2段階認証:** 大手企業への販売では求められることが多い機能です。
